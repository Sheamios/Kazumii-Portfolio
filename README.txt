# Roblox QA Tester Portfolio

## Files
- index.html — Home
- about.html — About, skills and testing process
- projects.html — Projects
- bugs.html — Bug report showcase
- contact.html — Contact
- style.css — Shared styling
- script.js — Animations and mobile navigation

## How to use
1. Open `index.html` in a browser.
2. Replace `YOUR NAME`.
3. Replace the placeholder statistics with your real numbers.
4. Replace project names/descriptions.
5. Add screenshots to the project cards.
6. Replace Roblox, Discord, GitHub and email links.
7. Edit bug reports so they reflect your real work.

No external libraries are required.
